# 🏎️ 자동차 판매 데이터베이스 샘플 데이터 생성 도구

이 프로젝트는 자동차, 제조사, 판매내역 테이블을 위한 대량의 사실적인 샘플 데이터를 생성하는 Node.js 스크립트를 포함하고 있습니다. SQL 연습 및 데이터 분석 테스트용으로 설계되었습니다.

## 📌 데이터 구조 (Schema)

데이터베이스는 다음과 같은 관계를 가집니다:
- **manufacturer (제조사)**: 자동차 제조사 정보 (국가, 설립연도 등)
- **car (자동차)**: 모델명, 가격, 연료 타입 (제조사와 1:N 관계)
- **sales (판매내역)**: 4,000건의 무작위 판매 데이터 (2024년~2025년)

---

## 🚀 시작하기

### 1. 필수 요구사항
데이터 생성을 위해 **Node.js**가 설치되어 있어야 합니다.

### 2. 라이브러리 설치
사실적인 한국어 데이터를 생성하기 위해 `@faker-js/faker` 패키지를 사용합니다. 프로젝트 루트 폴더에서 아래 명령어를 실행하세요.

```bash
npm init -y
npm install @faker-js/faker

node group_car.js
```
